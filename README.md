# TP1-Exo-4-Imtiaz-SAID-KAMLOUDEEN

Petit projet Java réalisé dans le cadre du TP1. Le but est de créer un programme qui simule le fonctionnement d'un magasin.

Le programme permet de :

Consulter les produits disponibles
Ajouter des produits au panier
Voir le contenu du panier et son prix total
Passer une commande
Gérer les stocks

Projet réalisé avec Java et NetBeans.
